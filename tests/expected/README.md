# Expected outputs

- `stub/` contains exact files generated by the deterministic Nextflow stub test. CI compares these byte-for-byte.
- `biological_expectations.tsv` contains minimum biological detection criteria for the real mock-community run.

The biological test intentionally does not require exact Kraken2/Kaiju counts because classifier assignment can differ between database structures and taxonomic descendants even when the expected organism is correctly recovered. Kraken2 expectations therefore use species-level clade reads rather than direct reads.
